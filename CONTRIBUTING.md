# Contributing to Caveman Output Style

## Ways to contribute

- Report bugs or suggest features via GitHub Issues
- Submit PRs to improve the style definition or documentation
- Share the repo with others who might find it useful

## Style guidelines

- Keep descriptions concise — this is a caveman project after all
- Test any style changes with Claude Code before submitting
- Keep the README accurate and up to date

## Process

1. Fork the repo
2. Create your branch
3. Submit a PR with a clear description of the change
